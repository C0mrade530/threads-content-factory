# Источники и проверенные границы

## Контент

Исходный Telegram-экспорт «База веток для Threads-Хаты» предоставлен пользователем. В `reference/` сохранены 351 полноразмерный JPEG и 351 служебная миниатюра, 64 сообщения с 318 пронумерованными пояснениями и OCR каждого изображения. Полный попарный маппинг «каждый пункт — конкретный JPEG» не заявляется: авторская подпись может стоять у первого или последнего изображения альбома, один пример может продолжаться на нескольких скриншотах. Сохранены порядок и исходные тексты.

OCR сделан локально Apple Vision для русского и английского, все слова вручную не вычитывались. Четыре служебных сообщения помечены отдельно. Исходные показатели охватов не проверены независимо. Генератор переносит механики, а не обещания охватов, чужие истории и цифры.

Снимки и тексты остаются материалами их авторов. MIT распространяется на программный код этого инструмента, не перелицензирует исходную подборку и не даёт гарантий прав на дальнейшее распространение чужих материалов.

## Интеграции

Контракты сверены 29 октября 2026 года по первичной документации:

- [Upload-Post — профили, identity и ссылка подключения](https://docs.upload-post.com/api/user-profiles/): `username` внутри social account — идентификатор, `handle` — имя для человека.
- [Публикация текста](https://docs.upload-post.com/api/upload-text/): Threads, async_upload, request_id, external_id, Idempotency-Key. Ключ идемпотентности действует у провайдера ограниченное время; локальный unknown не повторяет POST даже после этого периода.
- [Проверка статуса](https://docs.upload-post.com/api/upload-status/): результаты могут быть списком; общий success/completed без успешного Threads-результата и ссылки не считается доказательством публикации.
- [OpenAI Responses API](https://developers.openai.com/api/docs/guides/text): модель выбирает владелец сервиса через OPENAI_MODEL. Фоновая генерация использует отдельный API-ключ.
- [GPT Actions](https://developers.openai.com/api/docs/actions/getting-started), [API-key authentication](https://developers.openai.com/api/docs/actions/authentication).
- [MCP Python SDK v1](https://py.sdk.modelcontextprotocol.io/v1/): локальный stdio-мост; в зависимостях явно указано `mcp<2`.
